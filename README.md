# Interactive 3D Scatterplot | Python Plotly

A demonstration of an interactive 3D visualization using synthetic regional sales and profit values.

## Contents
- `Volcano2.py` — Python plotting example
- `Volcano Snapshot.png` — output preview

## Run
Install `numpy`, `pandas`, and `plotly`. Run `python Volcano2.py`.

## Skills
Interactive plotting and data visualization. The plot does not use volcano measurements.
